Humanize in the piano roll: what it actually does

By Tongkit Leong · September 24, 2026 · 7 min read

Humanize is a one-click tool in the Tracks piano roll that nudges every note's timing and velocity by a small random amount, so a clip that was drawn or quantized dead-on-grid picks up some of the looseness of a real performance. It doesn't change pitch, note length, or which notes exist — only when each one lands and how hard it hits.

What Humanize changes, note by note

Every note in a piano roll clip has a start time and a velocity, whether you played it in on a MIDI keyboard or drew it with the pencil tool. Humanize walks through every note in the selected clip and applies two independent random nudges: a small shift to the start time, forward or back, and a small shift to velocity, up or down. Each note gets its own random amount, so the result isn't a uniform shift of the whole clip — it's per-note variation, the same way no two hits from a real drummer land at exactly the same instant or exactly the same volume.

The nudges are deliberately small. Humanize is built to take the edge off something that's mechanically perfect, not to scramble the part. A note that starts squarely on beat one will still land close to beat one afterward — just not to the sample.

Why a perfectly quantized clip can sound stiff

Quantizing a part snaps every note to the grid, which is exactly what you want while you're getting the pitches and rhythm right. But a grid has no velocity information and no timing variation built in — every note sits at the same subdivision, and if you drew the notes instead of playing them, every note also defaults to roughly the same hit strength. Put those two things together and a pattern that's rhythmically correct can still sound like it was typed rather than played, because nothing about it varies from one note to the next.

That's the same problem covered from two different angles in quantize and swing explained and editing note velocity for a more human performance — swing shifts alternating notes for timing feel, and the velocity lane lets you shape volume by hand, note by note. Humanize does a version of both at once, automatically, across an entire clip in a single click.

How to use Humanize in Tracks

Step 1: Program or record the clip first

Get the part right before you loosen it up. Draw the notes in the piano roll, record them from a MIDI keyboard, or quantize a recorded take so the rhythm sits where you want it. Humanize is a finishing pass, not a substitute for getting the pitches and structure correct.

Step 2: Select the clip

Open the clip in the piano roll. Humanize works on the currently open clip, so make sure it's the one you actually want to loosen before running it.

Step 3: Click Humanize

The piano roll toolbar has a Humanize button. Clicking it applies a random timing and velocity nudge to every note in the clip in one pass — there's nothing to configure, and it takes effect immediately.

Step 4: Listen back and compare

Loop the clip and listen for whether the variation reads as feel or as sloppiness. A hi-hat pattern or a background chord stab can usually take more looseness than a lead melody that needs to land precisely on the beat to make sense.

Step 5: Undo, or run it again

Because Humanize creates an undo point before it runs, you can always step back to the exact quantized version if the result is too loose. You can also run it again on top of an already-humanized clip to stack more variation — but each pass pushes timing and velocity further from where you started, so it's usually better to undo and re-run once than to click it repeatedly.

Humanize vs. hand-editing vs. quantize and swing

These three tools solve the same underlying problem — a part that sounds too rigid — but they trade off speed against control.

  • Humanize is fastest: one click loosens timing and velocity across an entire clip at once. Best for a quick pass on a part you don't want to spend a lot of time hand-tuning, or as a starting point before manual touch-ups.
  • Swing, covered in quantize and swing explained, shifts alternating notes by a consistent, adjustable amount rather than a random one. It's the right tool when you want a specific, repeatable groove — a swung hi-hat pattern, for example — rather than raw looseness.
  • Manual velocity and timing edits, covered in editing note velocity, give you full control over exactly which notes are emphasized. This is the slowest option but the only one that can create intentional phrasing — accenting a downbeat on purpose rather than by chance.

In practice, the three combine well: quantize for correctness, swing for a deliberate groove, Humanize for a fast layer of looseness, then a manual pass on the handful of notes — a snare accent, the top note of a run — that need to be exactly right rather than randomly close.

Where Humanize helps, and where to skip it

Humanize tends to help most on parts with a lot of repeated, similar notes, where flat timing and velocity are most audible: hi-hat and shaker patterns, background chord stabs, arpeggiated fills, and doubled or layered parts where a small amount of drift between layers actually adds width.

It's worth being more careful with it on parts where precision matters for a reason beyond feel. A kick pattern that's meant to lock tightly with a bassline, as described in how to write a bassline that locks with the kick, or a kick that's driving a sidechain ducking effect as in sidechain compression explained, generally wants to stay close to the grid — timing drift there can blur the lock or make the ducking pump unevenly. A lead vocal melody or a hook that needs to land exactly on the beat to read correctly is also usually better shaped by hand than left to random variation.

Frequently asked questions

Does Humanize change pitch or note length?

No. Humanize only adjusts a note's start time and velocity. Pitch, note length, and which notes exist in the clip are untouched.

Does Humanize work on drum patterns, or only melodic parts?

Both. Drum patterns in Tracks are built from notes in the same piano roll data as melodic and chord clips, so Humanize applies the same way to a drum clip as it does to any other MIDI clip. See the free online drum machine guide for the rest of the drum programming workflow.

Will Humanize do anything to a recorded audio clip?

No. Humanize acts on note data, so it only affects piano roll and drum clips. A recorded audio track isn't made of individual notes, so there's nothing for Humanize to nudge; for timing changes on audio, see time-stretch and repitch instead.

Can I undo Humanize if I don't like the result?

Yes. Running Humanize creates an undo point, so a single undo takes the clip straight back to how it sounded before you clicked it.

Should I use Humanize before or after quantizing?

After. Quantize first to get the rhythm correct, then run Humanize on top to add variation. Humanizing before quantizing defeats the purpose, since quantize would snap the notes right back onto the grid and undo the timing nudge.
