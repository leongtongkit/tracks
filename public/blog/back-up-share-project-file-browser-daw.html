How to back up and move your music project between computers

By Tongkit Leong · October 16, 2026 · 6 min read

To move a Tracks project to another computer, click Save in the studio to download a .tracks.json file, copy that file across, then click Open in Tracks on the other machine. The file holds your tracks, notes, effects, and samples, so it also works as a backup that does not depend on your browser.

Why you need a file at all

Tracks has no account and no cloud storage. Your project is autosaved inside the browser you are using, and it never leaves your device. That is good for privacy, but it means the browser is the only place the project lives. A different computer, a different browser, or a different browser profile starts with an empty studio.

The project file is how you carry work across that gap. It is also your safety net if site data gets cleared. The reasons that can happen are covered in local storage and privacy explained.

Step 1: Save the project file

In the studio, click Save in the file bar. Your browser downloads a file named after your project, ending in .tracks.json. Spaces and symbols in the project name become hyphens, so "My Beat #2" turns into something like My-Beat-2.tracks.json.

Give the project a real name before you save. If you have ten files called "Untitled", you will not know which one is which in six months.

What the file contains

  • Every track, clip, and note, plus tempo and arrangement settings.
  • Instrument patches and mixer settings, including effect settings.
  • Any samples or recordings the project uses, embedded in the file as audio data.

Because samples are embedded, the file is self-contained. You do not need to hunt down separate audio files to reopen it. The trade-off is size: a project with long recordings makes a bigger file.

Step 2: Put the file somewhere safe

The download lands in your browser's usual downloads folder. Do not leave it there as your only copy. Move it to a place you already trust:

  • A USB drive or external disk, which is the simplest way to move between two computers.
  • A folder that your own backup tool or personal cloud drive already syncs.
  • An email to yourself, if the file is small enough to attach.

Tracks itself never uploads the file. Where it goes after the download is your choice.

Step 3: Open it on another computer

On the second machine, open tracks.jfound.net/studio in a current browser. Click Open in the file bar, and pick your .tracks.json file. The project loads with its tracks, notes, effects, and samples.

Open also accepts standard MIDI files (.mid). If you only need the notes, not the full project, see how to export a MIDI file.

A simple backup routine

Autosave covers accidents like closing the tab. It does not cover a browser reset or a lost laptop. A small habit covers both:

  1. Save a file at the end of every session in which you made progress you would hate to redo.
  2. Save another copy before a risky change, such as a big rearrangement. Name it something like "song-before-rearrange".
  3. Save a final file when a track is done, then keep it next to your exported audio.
  4. Keep two copies in two places, for example your computer and a USB drive.

Project file vs. audio export

These do different jobs, and you usually want both. A project file is your editable working copy. A WAV or MP3 is a finished render for listening and sharing, and you cannot turn it back into separate tracks. The guide to exporting MP3 and WAV covers the audio side.

Sharing a project with a collaborator

You can send the .tracks.json file to someone, and they can open it in their own browser. That is file exchange, not live co-editing: each person works on their own copy, so agree on whose version is current. For how this compares with cloud studios, see BandLab vs Soundtrap vs Tracks.

Troubleshooting

  • The file will not open. Check that it ends in .tracks.json and was not renamed or edited. A truncated download is a common cause, so download it again from the original machine if you can.
  • The project sounds different. Make sure the second computer has finished loading the studio before you press play, and check your output device and volume.
  • You opened it and lost track of which copy is newest. Save again right after opening and add a date to the project name.

Frequently asked questions

Does Tracks back up my project to the cloud?

No. Projects are stored in your own browser and never uploaded. The only backup is the file you download yourself.

Can I open my project on a phone or tablet?

If the device's browser can run the studio, you can open the file there the same way. Larger projects may be slow on small devices.

Will samples I recorded be included?

Yes. Samples the project uses are embedded in the file when you save, so the project comes back with its audio.

What if I cleared my browser data before saving a file?

The autosaved project is stored in that browser data, so clearing it usually removes the project. This is why saving a file at the end of a session matters.

Is the project file the same as a MIDI file?

No. A MIDI file carries only note data. The project file carries the whole session, including instruments, effects, and samples.
