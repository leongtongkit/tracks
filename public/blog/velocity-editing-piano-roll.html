How to edit note velocity for a more human-sounding performance

By Tongkit Leong · July 27, 2026 · 7 min read

Velocity is how hard a note was hit, and it's the single biggest reason programmed music can sound stiff: every note drawn at the same height plays back at exactly the same volume. In the Tracks piano roll, a velocity lane sits under the note grid so you can drag each note's hit strength up or down individually, turning a flat, mechanical part into one that actually breathes.

What velocity actually is

When a drummer hits a snare or a pianist presses a key, they rarely apply the exact same force twice in a row. Some hits land harder, some softer, and that variation in force is what velocity captures. On a MIDI keyboard, velocity is measured from how fast you push a key down. In the piano roll, every note carries a velocity value even if you never played it on a keyboard at all — drawing a note with the pencil tool still gives it a velocity, just a default one.

The practical effect of velocity is volume: a higher-velocity note plays back louder than a lower-velocity one, using the exact same pitch, the exact same instrument, and the exact same timing. Nothing else about the note changes. That's what makes velocity such a precise dial for dynamics — you're not touching a track fader or an EQ, you're adjusting how hard one specific note hits.

Why flat velocity sounds robotic

Drum machines and piano rolls make it trivially easy to draw a run of notes that are all identical — same length, same pitch, same everything, including velocity. That precision is exactly what a grid is good for. But real playing is never that even. A hi-hat pattern played by a drummer has natural loudness variation between hits even at a fast, steady tempo, and a bassline played by a bass player accents certain notes over others without thinking about it.

When every note in a pattern sits at identical velocity, the ear picks up on the sameness almost immediately, even if the listener couldn't name why the part sounds off. It's the same effect covered in quantize and swing explained, but for volume instead of timing: quantize removes timing variation, and flat velocity removes volume variation. A beat can have perfect swing and still sound dead if every hit is exactly as loud as the last one.

How to edit velocity in the Tracks piano roll

Step 1: Program or record the part first

Draw the notes in the piano roll, or record them from a MIDI keyboard, without stopping to fix dynamics yet. Get the pitches and timing right first — velocity editing is a pass you do afterward, on notes that already exist.

Step 2: Find the velocity lane

Below the main note grid in the piano roll is a labeled "VEL" lane. Every note in the clip has a matching bar in this lane, positioned directly under it, with the bar's height showing how hard that note currently hits.

Step 3: Drag bars up or down

Click and drag any bar in the velocity lane to change that note's velocity on its own — taller means louder, shorter means softer. Because each bar lines up with one note, you can pick out a single snare hit, a single chord stab, or a single bass note and adjust it without touching anything around it.

Step 4: Shape a phrase, not just individual hits

Random variation helps, but intentional shaping helps more. Push velocity up on the notes that should feel like the point of emphasis — the downbeat of a bar, the top note of a melodic run, the snare on beat two and four — and pull it down on connecting or passing notes around them. A bassline that locks with the kick, for example, often reads better when the notes landing under the kick hit harder than the notes filling space between kicks; see how to write a bassline that locks with the kick drum for the rhythmic side of that same idea.

Step 5: Use Humanize for a fast baseline pass

The piano roll toolbar includes a Humanize button that adds subtle random variation to both timing and velocity across every note in the clip at once. It's a fast way to knock the stiffness off a part you drew in with the pencil tool before you go back and hand-shape the notes that matter most. Humanize is a starting point, not a substitute for the manual shaping in Step 4 — random variation alone can't create the intentional accents a real performance has.

Where velocity matters most

  • Hi-hats and shakers — repeated fast notes are the first place flat velocity gets noticed, since the ear hears the same short sound over and over. Even small variation between hits goes a long way here.
  • Melodic lines — a melody with velocity shaped around its phrasing feels sung or played, not typed. Louder on the notes that carry the phrase, softer on the notes that connect them.
  • Chords and pads — less critical, since sustained sounds mask small velocity differences, but still useful for making a chord progression swell into a chorus rather than jumping in at full volume.
  • Basslines — velocity differences between the root notes and the passing or ghost notes help a bassline sit in the mix instead of pushing every note forward with equal weight.

Frequently asked questions

Does velocity change pitch or timing, or only volume?

Only volume. Velocity in Tracks changes how loud a note plays back; it doesn't move the note in time or change which pitch it plays. For timing feel, see quantize and swing explained.

What velocity does a note get if I draw it with the pencil tool instead of playing it?

A default mid-range velocity, which you can then drag up or down in the velocity lane like any other note. You don't need a MIDI keyboard to get dynamic variation into a part.

Can Humanize ruin a part if I click it more than once?

It can push timing and velocity further from where you left them each time you run it, so it's best used once on a fresh part, then followed by manual adjustment rather than repeated clicks. If a pass goes too far, undo and try again with lighter manual edits instead.

Does velocity affect drum machine patterns or only the piano roll?

Drum patterns in Tracks are built from notes in the same underlying piano roll data, so the velocity lane and per-note editing described here apply to drum tracks as well. See the free online drum machine guide for the rest of the drum programming workflow.

Is there a fast way to edit velocity in a browser DAW without a MIDI keyboard?

Yes. Open the studio, draw or select a clip, and drag the bars in the velocity lane under the piano roll — no MIDI hardware required. If you do have a keyboard, connecting it lets you record velocity from your actual playing instead of drawing it by hand; see how to use a MIDI keyboard in a browser DAW.
