Use YuE2 with Tracks: edit the songs it writes, and have it sing your melody

By Tongkit Leong · November 27, 2026 · 6 min read

YuE2 can write a song from a description and lyrics. It can also use a melody you give it. Tracks lets you open and edit that melody as sheet music, in the sheet music editor or in the studio, then save it for YuE2.

What is YuE2?

YuE2 is an open song model. It writes a score with a melody and chords before making the audio, and it can use a score you provide. Its official project page has examples you can hear.

Tracks is not part of YuE2 and isn't made by its team. Tracks does not run the model. It gives you a way to edit a score in your browser and save it as an ABC file.

What you need

To run YuE2 yourself, you need a computer with a strong graphics card. The hardware guide in the official repository lists the graphics cards and computers it supports, and a low-memory mode for smaller cards. Read the installation and generation instructions there before you start.

There is also an online version linked from the official GitHub page. At the time of writing, it makes songs from a text description and lyrics, or from an audio recording you upload as a cover. It does not take sheet music. The score steps below therefore use YuE2 running on your own computer.

Edit a YuE2 score as sheet music

The Tracks sheet music editor opens a YuE2 score as it is, without converting it. It shows the sheet music and the ABC text side by side, and the two stay in step. Click a note to pick it, then use the buttons or the keyboard to move it up or down, change its length, turn it into a rest, or add a chord name. You can also type in the text.

  1. Open the sheet music editor.
  2. Choose Open .abc and pick the song's score.abc, or drop the file on the page.
  3. Edit the notes. The Score check under the text uses the same rules as YuE2's own score check. It says in plain words what YuE2 would refuse, such as a bar that is too long for its time signature.
  4. Choose Save .abc. A score you open and save without changes stays exactly the same.

The note buttons keep every bar the right length and keep the two parts, Vocal and Ins, lined up, so the saved file stays in YuE2's format. YuE2 takes lyrics separately from the score, so the editor has a lyrics box that saves to its own text file. It works on a phone too. To hear the score with the studio's instruments or keep working on it there, choose Send to studio.

Bring a YuE2 song into the studio

When YuE2 saves a song, it includes a file called score.abc. ABC is a text format for music notation. It describes note pitches and lengths, and can include chord names, a key, a tempo and a time signature. Keep a copy of the original score before editing so you can return to it.

  1. Open the Tracks studio.
  2. Choose Sheet music, then Choose .abc file.
  3. Select the song's score.abc file. If Tracks asks about the current song, save it first if you want to keep it.
  4. Open the melody and chord clips to edit their notes.

You get an editable melody track and, when the score has chord symbols, a chord track. The tempo, time signature and key come in too. If the score has another melody voice with notes, it gets its own track. Lyrics in an ABC file do not come in. Tracks tells you if it had to skip or adjust anything else.

Listen to the melody and chords together. Move a melody note, change its length, or adjust a chord in the piano roll. A chord is a group of notes that start together. To change the harmony, move or replace those notes together. It helps to keep a separate copy of the original while you try ideas.

When you are ready, open Sheet music again. Choose your melody track and the Chords track, then select Download .abc, or Edit as sheet music to check and polish the score in the editor first. Give the edited file back to YuE2 with cot="full" to use the melody and chords. The official examples show how to run a score. Listen to the result: a score guides the model, and the audio may not follow every detail exactly.

Write a melody in Tracks

You can start with a blank song instead. Add an instrument track, create a clip and draw a melody in the piano roll. Use one note at a time. If notes overlap, export keeps the top note and tells you. Put notes on the grid; export chooses a fine enough grid when it can, and reports when it needs to move notes slightly.

If you want to supply harmony, add a separate track with block chords: the notes of each chord should begin at the same time. Choose that track in the Chords menu when you export. If the track has individual notes, arpeggios or chords that cannot be named, Tracks leaves the chords out and tells you. You can also choose No chords and leave the accompaniment up to YuE2.

  1. Open Sheet music in the file bar.
  2. Choose the melody track under Melody from.
  3. Choose a chord track or No chords.
  4. Choose Download .abc and read any message shown.

Put the downloaded score where your YuE2 installation can read it. Use your lyrics and style with the generation setup in the official examples. For a melody-only file, the example command has this shape:

python examples/generate.py --abc-file my-melody.abc --cot melody --output outputs/melody

Use --cot full when the file includes chords. The example's lyrics and melody use about one sung syllable per note. That is a useful starting point when writing your own words, though you can experiment. Check the examples README for the full setup and input files.

No graphics card?

You can still make a melody in Tracks. Export it as WAV or MP3, then use the online version's cover feature with your lyrics. Our guide to exporting a song as MP3 or WAV walks through the download. In this route you upload audio, not the ABC file, and the online service makes a cover from the recording.

Licence

YuE2's model has its own licence, MODEL_LICENSE in the official repository: read it to see how you may use the songs it makes.

Try it

Open the sheet music editor and write a few bars, or make a short melody in the Tracks studio and use Sheet music to download it. A few bars are enough to learn the path from your notes to a score you can use with YuE2.
